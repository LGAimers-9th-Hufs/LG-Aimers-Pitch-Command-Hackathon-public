## §0 요약

팀 최고 제출(853.57)은 **LightGBM 2종 확률평균 + 분산수축 캘리브레이션**이고, 우리 트랙(500.61)과의
+353 격차는 **알고리즘이 아니라 세 가지 설계 결정**에서 나온다. 셋 다 우리가 정반대로 하고 있었다.

| 설계 결정 | june853 | 우리 | 측정된 대가 |
|---|---|---|---|
| **학습 시즌** | **최신 1시즌만** | 2019~2024 전부 | **530점** (707.9 vs 319.0) |
| out-of-support 컬럼 | `season`·`pitcher_id`·`batter_id` **제거** | 전부 포함 | z_asof 사례 −192 |
| 신뢰도 수축 | `p_sm500` = **행 단위** (rate·n+250)/(n+500) | z_asof = **train 유래 룩업** | 룩업은 시즌 누적 드리프트를 그대로 맞음 |

**재현 확인**: fit 2023 → val 2024에서 raw **673.24**(원본 보고 683.10) · cal **707.90**(보고 712.79).
1.5% 이내로 재현되므로 이후 실험의 기반으로 삼을 수 있다.

**개선 결과**: 그리디 앙상블(LGBM 2 + ExtraTrees 3) → **745.49**, 캘리 재적합 → **753.35 (+45.5)**.
전이 이득(+145.7, 707.9 → 853.57)이 유지된다면 2025 기대 **≈ 899**.

## §1 원본 레시피 (전문 복원)

- **모델**: `lgbm_l7.txt`(num_leaves 7 · min_data_in_leaf 1500 · 500 iter · seed 49),
  `lgbm_l15.txt`(15 · 1000 · 400 iter · seed 57). 가중 0.5/0.5.
- **공통 파라미터**: `objective=regression`(**Brier 직접 최소화** — 지표가 곧 제곱오차),
  `learning_rate 0.03`, `lambda_l1 0.5`, **`lambda_l2 8`**, `feature_fraction 0.85`.
  우리 HGB(leaf 31 · min 200 · l2 1.0)보다 **훨씬 강한 정칙화**다.
- **피처 53개** = 공식 44 + 범주형 3(정수 매핑) + 파생 6:
  `count_code`(=b·3+s) · `p_logn`/`b_logn`(log1p n) · **`p_sm500`/`b_sm500`** · `prev{1,3,5}_fill` · `hand_match`
- **제거**: `row_id`, `season`, `pitcher_id`, `batter_id`
- **후처리**: `p* = 0.5 + 0.91·(p − 0.5) − 0.01` (분산 수축 + 미세 이동)
- `game_type` 매핑이 `{"P":0,"R":1}`이라 실제 값 `F`는 −1로 떨어진다 — train/test 일관이라 무해.

## §2 학습 시즌이 최대 레버 (val 2024 실측)

| 전략 | raw | cal(0.91,−0.01) | 캘리 재적합 |
|---|---|---|---|
| **2023 단독** | **673.24** | **707.90** | 707.90 |
| 2022+2023 (2023×8 가중) | 643.03 | 691.45 | 691.77 |
| 2022+2023 (2023×4) | 620.86 | 679.34 | 680.12 |
| 전체·decay 0.3 | 589.79 | 657.86 | 661.39 |
| 2022+2023 (균등) | 341.84 | 469.70 | 499.88 |
| **2019~2023 전체** | **142.64** | 319.04 | 395.10 |

**오래된 데이터는 넣는 만큼 단조롭게 나빠지고, recency 감쇠 가중으로도 회복되지 않는다.**
캘리 재적합이 레벨을 고쳐도 격차가 남는다 → 레벨뿐 아니라 **조건부 구조 자체가 낡는다**.
(기저율 2019 .5647 → 2024 .4861 단조 하락이 배경.)

⇒ **2025 예측 모델은 2024 한 시즌만으로 학습한다.** june853의 `training_season: 2024`가 이것이다.

## §3 다양성 — ExtraTrees가 답 (fit 2023 → val 2024)

| 변형 | cal 점수 | 기준과의 RMS | 기준+변형 최대이득 |
|---|---|---|---|
| **sk_et** (ExtraTreesRegressor) | 689.6 (raw **685.5**) | **0.0219** | **+30.8** |
| sk_rf (RandomForest) | 632.7 | 0.0212 | +8.9 |
| lg_extra (extra_trees=1) | 595.9 | 0.0229 | +5.4 |
| lg_ff30 (feature_fraction .3) | 642.4 | 0.0184 | +4.9 |
| sk_hgb | 692.1 | **0.0089** | +1.1 |
| lg_dart | −196.4 | 0.0522 | −36.2 |

**교훈**: `sk_hgb`는 점수가 가장 높지만(692) 불일치가 0.0089라 이득이 없다. `lg_dart`는 불일치가
가장 크지만(0.052) 단독 성능이 붕괴해 해롭다. **"같은 급이면서 다르게 틀리는" 좁은 창**이 값을 하고,
현재 그 창에 든 유일한 계열이 **ExtraTrees**다(완전 무작위 분할 = 부스팅과 편향 구조가 다름).

### 그리디 앙상블 (Caruana, val 2024)

```
june_l15 0.325 · june_l7 0.200 · et_l100_d28 0.200 · et_l200_d20 0.175 · et_l400_f05 0.100
→ cal 745.49  (기준 707.90, +37.59)
캘리 재적합 (slope 1.03, shift −0.005) → 753.35  (+45.45)
```

**블렌드 후 최적 slope가 0.91 → 1.03으로 오른다**(>1). 블렌드가 이미 분산을 줄였으므로 추가 수축이
불필요해진 것 — 과적합이 아니라 원리적 결과다. 캘리 상수는 **앙상블 구성이 바뀔 때마다 다시 잡아야 한다.**

**스트레스 폴드(fit 2022 → val 2023, 기저율 −0.029 급락한 파단 연도)**: 절대점수는 −1215로 음수지만
앙상블 이득은 **+12.7**로 부호가 유지되고, 캘리 재적합이 **+355**로 결정적이다.
단일 시즌 학습은 기저율이 급변하는 해에 취약하다는 것도 같이 보여준다(2025는 완만해서 통했다).

## §4 1000점까지 남은 것

현재 경로 기대치: 753.35(로컬) + 전이 145.7 ≈ **899**. 1000까지 **약 100** 부족.

1. **새 계열 추가** — NN/TabM(A100). ET가 +45를 준 것처럼, 부스팅·배깅과 또 다른 편향 구조가 필요하다.
   현재 멤버는 전부 트리다.
2. **LGBM 파라미터 자체 탐색** — 원본 파라미터가 최적이라는 근거가 없다. leaves·lambda·iteration 스윕.
3. **멤버 수 확대** — 이득 계수가 (1−1/M). 현재 유효 M≈3.
4. **피처** — 이제 **작동하는 검증 프로토콜**(fit 최신시즌 → val 다음시즌)이 생겼으므로, 기각됐던
   arm들(트랙맨 물리 프로필 N13 등)을 이 프로토콜로 재심할 수 있다. 단 **행 단위로 계산 가능한 형태**여야
   한다(룩업은 §1의 z_asof 실패 형태).

## §5 재현 방법

```bash
python sweep/lgbm_family.py --validate            # 원본 재현 (raw 673 / cal 708)
python sweep/lgbm_family.py --variants            # 다양성 변형 스캔
python sweep/lgbm_family.py --push                # ET 격자 + 그리디 앙상블 + 캘리 재적합
python sweep/lgbm_family.py --push --fit 2022 --val 2023   # 스트레스 폴드
```

`lightgbm==4.6.0` 필요(로컬·서버 핀 venv 모두 설치 완료). 서버는 `requirements.txt`에 이 한 줄로 설치된다 —
**LightGBM은 제출 가능한 계열이다**(우리가 "미설치"로 배제했던 전제가 틀렸다).
