# 최종 후보 설계도 — 투수 다음 투구 제구 성공 확률 예측

> 4개 리포트(`01`~`04`)의 결론을 하나로 통합한 실전 설계도.
> **철학**: GBDT를 앵커로 고정하고, GBDT가 구조적으로 못 먹는 신호(순서 시퀀스 · 엔티티 상호작용 · 캘리브레이션된 매치업 사전확률)만 **검증된 브랜치로 보강**. 모든 추가는 시간분할 CV LogLoss 개선으로만 채택.

## 0. 전제 & 미확정 블로커

**확정 (근거 기반):**
- 문제 = 투구 단위 **이진 확률 예측**, 시간분할(2019~24 학습 / 2025 hidden).
- 앵커 = 잘 튜닝된 **GBDT + as-of 피처**. 외부/딥 방법은 캘리브레이션 확률에서 GBDT를 **단독으로 이긴다는 직접 근거 없음** → "보완/앙상블"로만 진입.

**🚨 미확정 (이게 정해져야 설계 확정):**
- [ ] **"제구 성공" 라벨 정의** (별첨 컬럼 정의서) — 성공 판정 기준(의도 타깃 거리? 존? 심판콜?)에 따라 타깃·목적함수 달라짐.
- [ ] **평가지표** (LogLoss / AUC / Brier). 본 설계는 **LogLoss/Brier(확률)** 가정.

## 1. 공통 기반 (모든 후보가 공유 · 비협상)

```
[누수 안전 피처 레이어]  ── 모든 통계는 strict shift(1) 후 rolling/expanding (as-of)
   ├ 게임상태: 카운트(12범주), outs, 이닝, 점수차, 주자, 타순회차
   ├ 중요도: Leverage Index, Win Expectancy, 상호작용(LI×count 등)
   ├ as-of 이력: career/season/last-N 제구율, 카운트·구종별 제구율, streak/EWMA
   ├ 피로: 아웃팅 누적 투구수, 휴식일, 시즌 워크로드
   ├ Trackman(과거만): 릴리스 일관성(rolling std), 무브먼트·스핀 delta
   └ 익명 ID: CatBoost ordered CTR / OOF target enc + 베이즈 수축
        ▼
[검증]  시간순 forward-chaining + GAME 단위 그룹분할 (랜덤 KFold 금지)
        ▼
[캘리브레이션]  최신시즌(2024) 홀드아웃서 isotonic/Platt → reliability diagram
```
⚠️ **누수 1순위 리스크**: 예측 대상 투구 *자신의* Trackman 실측(구속·스핀·실제 로케이션) 입력 금지.

## 4. 단계별 빌드 순서 (각 단계는 CV LogLoss 개선으로 게이트)

| Phase | 내용 | 게이트 통과 조건 | 대응 후보 |
|---|---|---|---|
| **0** | 데이터 로드 + 공통 피처 레이어 + 시간 CV + 리샘플링 없이 자연비율 | 파이프라인 무결성·누수 0 확인 | 기반 |
| **1** | **GBDT 앵커** (LGBM/XGB/CatBoost) + isotonic 캘리 | 견고한 baseline LogLoss 확보 | **A** |
| **2** | **③ 베이지안 log5 사전확률**을 as-of 컬럼으로 주입 | LogLoss 개선 시 채택 (최저위험 우선) | **C-1** |
| **3** | **④ 엔티티 임베딩 + ① 시퀀스 임베딩** 컬럼 주입 | OOF LogLoss 개선 시 채택 | **C-2** |
| **4** | **딥 베이스러너**(TabM/RealMLP, 내부에 ①②④) → 메타 스태킹 → 블렌드 재캘리 | 블렌드가 단독 GBDT 초과 시 채택 | **B+C** |

원칙: **강한 baseline을 못 이기는 브랜치는 버린다.** 복잡도는 근거로만 증가.

## 5. 기존 A/B/C 후보 → 최종 통합 매핑

- **A (안전 주력)** = Phase 1. GBDT 앵커 + as-of 피처. **점수의 8할은 여기 피처 엔지니어링.**
- **B (다양성)** = Phase 4의 딥 베이스러너. CTR·시퀀스 도메인의 ①②④가 **B의 내부 구조**가 됨.
- **C (창의성/피처주입)** = Phase 2~3. ③베이지안 + ①시퀀스임베딩 + GNN임베딩을 **컬럼으로 흡수**.
- **가로축 xCTRL(◇)**: 라벨 정의 + 의도조건 피처로 전 단계 관통 (가산점).

---

## 6. 검증·캘리브레이션 프로토콜 (비협상)

1. **시간순 forward-chaining**: train 2019–22→val 23, →val 24. GAME 단위 그룹분할.
2. 각 fold 내 인코딩·rolling을 **그 fold 과거만으로 재계산**.
3. BCE(LogLoss) 학습. **SMOTE/리샘플링 금지**(Brier 악화, 2603.00208) — prior/캘리로.
4. 각 모델 시간-전진 홀드아웃서 **isotonic/temperature 재캘리**.
5. 스태킹 후 **블렌드 재캘리** ("calibration trap", Ensembling-TFM 2026).
6. Brier/LogLoss + reliability diagram + **per-count/per-leverage 슬라이스**로 매 단계 baseline 대비 검증.

## 7. 💡 창의성(가산점) 레이어

- **Expected Command (xCTRL)**: 의도 GMM/베이지안 사후 미스거리로 제구 정량화 (리그평균 지표보다 연도간 안정).
- **상황·레버리지 조건부 제구 안정성** (강한 EB 수축; clutch는 대부분 노이즈라는 정직한 서사).
- **일관성 vs 조절력**: 아웃팅 내 릴리스 분산 = 피로/조절 프록시.
- **SHAP 해석 레이어**: 카운트·LI·직전미스·릴리스일관성으로 예측 귀속 → 스카우팅 리포트.

## 8. ❌ 제외 (근거 기반)

- LLM/RL을 **확률 예측기로** (03 리포트: LogLoss/Brier에서 GBDT 패배)
- RL 피처선택/AutoML/HPO (랜덤서치·OpenFE가 이김)
- 딥 CTR/DLRM/트랜스포머 **drop-in 대체** (시간분할서 트리 승·캘리 나쁨)
- DCNv2/xDeepFM 크로싱넷 (GBDT가 이미 저차 상호작용 포착, 델타 ~0.001)
- TabPFN-3/파운데이션을 **예측기로** (행수·컨텍스트 제약; 오프라인 피처 증류만 가능)
- IRL/자기회귀 월드모델을 **예측기로** (지표 불일치)
