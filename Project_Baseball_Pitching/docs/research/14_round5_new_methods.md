# 14 — 라운드 5: "1100을 여는 새 레그"의 정보 축 (2026-08-29 밤)

> 3-스트림 병렬 조사(S1 아키텍처 · S2 대회 레시피+KBO 규칙 · S4 내부 정보축)의 통합.
> 목표 스펙: 새 레그 **LB ≥1000 (로컬 ≥901) & 정직 d ≥ 0.0344**(S=1045면 0.0314, D4 5레그 기준).
> 전 인용은 각 스트림에서 실개방 검증됨(UNVERIFIED 표기 예외). 판정표(메모리

**T1 TabPFN-3 = 킬 확정 (사전 등록 기준 ① 발동, 슬롯 0·약 3시간).**
같은 컨텍스트·같은 82피처로 학습한 LGBM(june풍)과의 쌍대 비교(30k/4k 프록시 행):

|---|---:|---:|---:|---:|
| ctx 100k · 기본 ckpt · n_est 1 | −367.6 | +65.0 | **−432.6** | 158 |

- 컨텍스트 확대(100k→245k)가 **역방향**(스케일링 구제 없음), 특화 ckpt도 더 나쁨.
- d(D4평균) 0.058~0.062로 컸으나 grok(728)형 "틀려서 생기는 다양성" — 무가치.
- 공학 소득: RTX3080 10GB에서 `fit_with_cache + kv int8 + TABPFN_MAX_BATCHED_TEST_ROWS=1024`
  조합이 스필을 제거(2.69s/1k, VRAM 8.1GB). 속도는 해결 가능했으나 정확도가 죽었다.
- 해석: Beyond IID(arXiv:2606.30410)의 "temporal + 엔지니어드 피처 → GBDT" 판정이 v3에도
  연장됨을 우리 게이트가 첫 독립 실측. 벤더 temporal 벤치(회귀 한정)는 이 세팅을 대변하지 않았다.
- ⇒ **결정 트리대로 다음 빌드 = T1.5 (TM-표현 NN 레그).** xRFM/GRANDE(T3)는 temporal 무증거
  함수족이므로 T1.5·T2보다 후순위 유지.

## 0. 결정 먼저 (파일럿 이전 시점의 기록 — 위 0-b가 최신)

**다음 빌드 = TabPFN-3 파일럿 레그.** 이유 세 줄:
① 킬 리스트 재개방 요건을 충족한 유일한 후보(temporal prior + 1M행 지원 + temporal-split에서
튜닝 GBDT 상회 — 단 벤더 벤치, 우리 게이트가 첫 독립 검증이 된다).
② d 기제가 "함수족 교체"(실측 상한 0.026)가 아니라 **합성 SCM prior에 대한 베이지안 ICL** —
오차 생성 방식 자체가 다르다. 대회 근거: DACON 미래-홀드아웃(전력)에서 TabPFN 단독 Private 1위.
③ **학습 0시간** — 게이트+정직 d 판정까지 1~2일, 슬롯 0. 킬돼도 최소 비용.

킬 시 주력 = **TM-표현 NN 레그**(S4 1위), 병행 안전판 = **전시즌 era-가중 GBDT 레그**(S4 2위).
잔여 일정 4~7일에 정확히 들어맞는 배치다.

## 2. 스트림 간 수렴 (교차 검증된 사실)

- **TFM 축**: S1(TabPFN-3 재개방)과 S2(DACON TabPFN Private 1위 선례 + AutoGluon TFM+GBDT 앙상블
  이득)가 독립적으로 같은 곳을 가리킴. 합법성은 규칙 §2-1이 명시 해소("공개 가중치 + 비상업
  이상 라이선스 허용") — 잔여 확인 = HF 게이트 다운로드가 "누구에게나 공개"에 해당하는지(클릭스루,
  Llama식 — 문제없다고 판단하나 조항 원문 팀 확인 권장) + ckpt를 zip에 동봉해 Phase 3 재현 보장.
- **1198 역설계** (산수: 격차 139.4 = ΔBrier 3.49e-4 = is4의 3.3배. 평균 1100급 레그 블렌드도
  실현이득 98이 필요한데 우리 최대 실측 71.8 — **솔로 1100급이 존재해야 하는 점수**):
  - 합법 후보: ① **as-of/당해시즌 분해의 심화**(우리 +42의 상위판 — 세그먼트·상대별 분해; S2가
    "가장 개연성 높은 합법 단일 요인"으로 지목, T2 레그에 반영) ② TFM/이종 레그 다양성(+수십).
  - 불법 후보: ① **test 배치에서 2025 in-season as-of 재구성**(+100급 설명 가능, 최유력 —
    우리가 tm3L에서 제거한 바로 그 패턴의 완전판) ② 배치 캘리(존 이동으로 δ가 크면 4e5·δ²)
    ③ LB 역산. ①②는 Phase 3 코드 검증에서 노출되는 유형 — **최종 순위는 집행 강도에 달렸고,
    우리의 컴플라이언스 규율이 곧 베팅이다.**
- **시퀀스 축**: S2(대회 선례)와 S4(행 합법성 감사)가 합쳐져 "train-고정 이력만 합법, 2025
  시퀀스는 사망"으로 정리 — T3 강등.

## 4. T1 실행 계획 — TabPFN-3 파일럿 (승인 후 착수)

1. **접근**: HF `Prior-Labs/tabpfn_3` — 계정 토큰 수락 필요(**유저 액션**: HF 로그인+약관 클릭).
   `pip install tabpfn` + ckpt 로컬 저장(`model_path=` 오프라인 로드 공식 지원).
2. **게이트**(시간분할, 기존 `real_data.make_folds` 프로토콜): 컨텍스트 {2023 단독 → 2024 예측,
   2022-23 → 2024} 두 설정 × 30k 프록시 → 로컬 점수. 채택선 **≥901**.
3. **정직 d**: 2024 프록시에서 D4 레그들과 RMS — 컨텍스트는 2023년말 시점 정합(p23 원칙 그대로).
   채택선 **≥0.031**.
4. **추론 시간 실측**: 245,789행 × 컨텍스트 250K/100K, fp16 — L4 환산 10분 이내 확인.
   초과 시 공식 증류 경로(dataset-specific 학생 — "Teacher≠submission" 독트린과 일치).
5. **§5 확증**: 행별 예측 ≡ 배치 예측 패리티(`test_regulation.py`) — 쿼리 간 어텐션 부재 증명.
6. 통과 시: ckpt 동봉 패키징 → scan BLOCK 0 → verify → blendF(5레그: D4+tabpfn3) 산수 후 제출.
   전 과정에서 **킬 기준(§1 표) 발동 시 즉시 T1.5로 전환.**
