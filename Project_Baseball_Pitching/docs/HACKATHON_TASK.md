## 1. 미션

투구 단위(pitch-level)로 **그 투구가 제구에 성공할 확률**을 예측한다.
투구 **직전까지** 확인 가능한 정보만 사용. 학습 2019~2024 → hidden test 2025.

## 2. 타깃 `control_success`

- train은 이진 라벨(성공 1 / 실패 0), 제출은 **0~1 확률**.
- **라벨 = 공의 위치 기준**(심판 콜이 아님). 다음 3가지가 **실패**, 그 외 유효 투구는 성공:
  1. 스트라이크존 **가운데 부근**으로 들어간 공 (한복판)
  2. 스트라이크존에서 **크게 벗어난** 공
  3. **포수의 요구 방향과 반대**로 들어간 공
- → 성공 영역은 **도넛(링)**. 성공확률은 존 중심 거리에 대해 **비단조**이며,
  "제구력 = 존에 넣기"가 아니라 **의도(조준점) × 실행 정밀도**의 곱이다.
- 임계값(가운데/크게 벗어남의 수치 기준)은 비공개. 라벨 산출에 쓰인 현재 투구의 사후 정보는
  입력으로 제공되지 않는다.

### 시즌별 실제 성공률 (train 실측)

| 시즌 | 행수 | 성공률 |
|---|---|---|
| 2019 | 237,413 | 0.5647 |
| 2020 | 244,087 | 0.5327 |
| 2021 | 247,088 | 0.5328 |
| 2022 | 247,472 | 0.5289 |
| 2023 | 245,525 | 0.5000 |
| 2024 | 253,507 | **0.4861** |

**단조 하락**(6년 −8pt). 2025는 더 낮을 개연성이 크다 → 지표가 Brier이므로 이 드리프트가
점수를 지배한다(§7 참조).

### 입력 47컬럼 구성
- **식별/경기**: `row_id` `season` `game_month` `game_dayofweek` `inning` `top_bottom`(T/B) `game_type`(R/F)
- **카운트·점수**: `balls_before` `strikes_before` `outs_before` `run_*_before` `score_diff_home` `score_diff_pitcher_team`
- **주자·중요도**: `runner_on_{1b,2b,3b}` `num_runners_on` `base_state`(8종) `home/away_win_expectancy` `li`
- **선수/팀**: `pitcher_id`(792명) `batter_id`(830명) `pitcher_hand` `batter_hand` `pitcher_team_id` `batter_team_id`(각 13)
- **과거 이력 `asof_*` 19개** (주최측 사전계산, 투구 직전까지만 반영):
  성공률·**역방향률**·**한복판률**·볼률·스트라이크률 / 직전 1·3·5경기 성공률·한복판률 /
  타자측 성공률·한복판률 / 구종믹스(fastball·breaking·offspeed) + 각 표본수
  - ⚡ **실패 3유형 중 2유형(한복판·역방향)의 투수별 과거 비율이 공식 피처로 제공된다.**
    유형 구성비 = 성공률과 직교하는 "실패 스타일" 축.
  - 결측: prev1/3/5 계열 약 2.0%, 나머지 rate 계열 0.05% (cold-start)

### 트랙맨 로그 (보조)
30컬럼: 구속(`rel_speed`,`zone_speed`) 회전(`spin_rate`) 무브먼트(`induced_vert_break`,`horz_break`)
릴리스(`extension`,`rel_height`,`rel_side`) 구종(`tagged/auto_pitch_type`,`pitch_type_group`) + 경기/타석 맥락.
- ❗ **투구 위치(PlateLoc) 컬럼은 없다** → 트랙맨으로 라벨 실패유형을 위치 복원하는 접근은 **불가능**.
- ❗ **ID 체계가 메인 데이터와 완전히 분리**: `pitcher_trackman_id`(906명, 5만~7천만 범위)와
  `pitcher_id`(792명, 20700~24633) **교집합 0**. 팀도 실명(`MIN_*`=2군)이라 직접 조인 불가.
  → 트랙맨 활용은 **엔티티 매칭(entity resolution) 과제**로 격상. 단서: 시즌·팀·손·투구수·**구종믹스**
  (메인의 `asof_pitcher_{fastball,breaking,offspeed}_rate`와 대응 계산 가능).
- 트랙맨엔 실제 `game_date`가 있으나 메인엔 월·요일만 있다.

## 5. 평가지표 (확정)

```
Score = max(0, 100000 × (1 − Brier / (r(1−r))))
Brier = mean((p_i − y_i)²)
r     = 평가 데이터 전체의 실제 평균 성공률 (비공개)
```
- Public = 테스트 100%, **Private = 종료 시점 Public** (셰이크업 없음).
- **수료 기준: Public ≥ 549.51** (운영진 베이스라인 RF를 평가 환경에서 실행한 점수).
- Phase 3(오프라인, 약 100명) 진출: Private 상위 + 코드·PPT 제출 및 검증 통과.

## 7. ⚡ 이 대회의 지배적 사실 — base-rate 정합이 모델 신호보다 크다

지표가 Brier이므로, 예측 평균이 실제 성공률에서 `d`만큼 어긋나면 손실 ≈ `d²/(r(1−r))`.
`r≈0.49`에서 **d=0.03이면 약 −360점**(베이스라인 총점이 549인 대회에서).

실측(val 2024, train ≤2023 · 상세는 `11_real_data_s0.md`):

| 예측 | Score |
|---|---|
| 상수 = train 전체 평균 0.5316 | **−828** |
| 상수 = 3시즌 선형 외삽 0.4877 | −1.1 |
| 베이스라인 RF, 무보정 (예측평균 0.5012) | 415.6 |
| 베이스라인 RF + 평균 외삽 보정 | **505.9** |
| RF + 실제 r 보정 (상한) | 507.0 |

→ **보정 하나가 +90점.** 반대로 2023 폴드에서는 RF가 기후값보다 **나빴다**(−660):
조건부 신호는 매우 약하고 시즌 시프트에 취약하다. 전략의 1순위는 신호 발굴이 아니라
**캘리브레이션(평균 + 기울기) 정밀화**다.

## 9. 확정으로 **폐기·변경된 기존 가정** (정정)

| 기존 계획 | 판정 | 사유 |
|---|---|---|
| 게이트 지표 = LogLoss | **→ Brier Skill Score** | 공식 지표 확정 |
| 자체 as-of 피처(F1 계열)를 직접 계산 | **폐기** | 2025 test에서 계산 불가(행 독립성 규정). 공식 `asof_*`로 대체 |
| P4 test pseudo-label | **금지** | 별첨 §5 명시 |
| P1 adversarial validation (train vs 2025 입력) | **불가** | 2025 입력을 로컬에서 볼 수 없음(test 5행). train 내 대리 AV로 축소 |
| 라벨 = 심판 콜 → ABS 3체제 concept shift | **약화** | 라벨은 위치 기준. ABS는 covariate/행동 시프트 + 존 기하 경계 이동으로 재분류 |
| 트랙맨 PlateLoc로 실패유형 복원 → 멀티태스크 | **불가능** | 트랙맨에 위치 컬럼 없음 |
| 트랙맨을 투수 프로필로 조인 | **조건부** | ID 체계 분리 → 엔티티 매칭 선결 |
| 경기 단위 group CV | **불가** | 메인 데이터에 game_id·game_date 없음(월·요일만) |
| C5 최근윈도우 재캘리·prior-shift | **최상위로 격상** | §7 실측으로 확인 |
