# 후보 파이프라인 전체 카탈로그 (실험 메뉴)

> "처음부터 완벽할 필요 없음. 나중에 태스크로 더 좋은 모델을 찾는다" 전제.
> **가능한 후보를 전부 나열**하고 각각에 ID를 부여 → 라벨/지표 확정 후 벤치마크 태스크로 순차 실행.
> 추천 통합 설계는 [`05_final_blueprint.md`](05_final_blueprint.md). 근거·검증은 `01`~`04`·`07`·[`09`](09_new_candidates_and_related_research.md)·[`10`](10_contextual_environmental_factors.md) 리포트, 논문은 `papers/`.
> M24~M36, F15~F23, T-e/f, C4~C6, E3/E4, 축 E(P1~P8)는 09(5방향 병렬 조사)에서 추가.
> **F24~F36(맥락·환경·생체: 경험곡선·복귀·구장·ABS-era 등)은 10에서 추가** — 각 arm에 가용성 태그(✅ 익명 파생/⚠️ 별첨 컬럼 필요/❌ 규정상 보류).

**티어 표기**: T1=필수 baseline · T2=강력 주력 · T3=신규 신호 브랜치 · T4=실험적/롱샷 · T5=낮은 사전확률(그래도 실험).
**GBDT 대비**: 앵커 / 보완 / 동률 / 짐 / 미검증.

> ## ⚠️ 탐색 원칙 — 근거는 "판정"이 아니라 "사전확률(prior)"
> - 이 문서의 티어·"GBDT 대비"는 **일반 벤치마크에서 *보통* 그렇다**는 사전확률일 뿐, **이 데이터·이 라벨에서 *반드시* 그렇다**는 보장이 아니다. 특이한 "제구 성공" 라벨에서 롱샷이 서프라이즈로 이길 수 있다.
> - **어떤 후보도 하드 제외하지 않는다.** 티어는 **예산 배분**에만 사용: 고-prior(T1~T3)에 ~70~80%, **롱샷/저-prior(T4~T5)에 실제 ~20% 탐색 예산**.
> - **채택 여부는 prior가 아니라 공정한 CV 게이트가 결정.** 시간분할 LogLoss에서 baseline을 이기면 논문이 뭐라 했든 채택.
> - **공정성 필수**: 롱샷을 불리하게(임베딩·전처리·튜닝 예산 없이) 돌리면 "가짜 prior"를 제조하게 됨. 각 방법에 공정한 조건을 줘야 서프라이즈가 드러난다.
> - 즉 아래 표는 **실험할 가설 목록**이지 결론이 아니다.

## 추천 실험 스윕 순서 (라벨·지표 확정 후)

각 단계는 **시간분할 CV LogLoss가 이전 최고를 이길 때만** 다음으로:

0. **S0 (사전 진단, 라벨 확정 즉시)**: **P1(adversarial validation — 10의 시즌 시프트 연대표가 타깃 목록)** + **P5(CV 메타실험)** + P7(hot-hand 진단) + 이벤트율 드리프트 측정(시즌별!) — 이후 모든 결정의 입력
1. **S1 (baseline)**: M0 → M1/M2/M3 각각 + F1·F2 + **F29(ABS-era)·F30(시즌 상대화)** + C1 → 최고 GBDT 선정. **C6(클립+3지표 리포트)은 전 단계 공통 장착**
2. **S2 (주력)**: 선정 GBDT + F3·F4·F5 + **F15(위치가치 그리드)·F18(미니 Kirby)·F19(피로 확장)·F24(경험곡선)** + M4 스택 + C2 + **P2(recency)·P3(refit)·F31(2024 가중/재캘리)**
3. **S3 (저위험 신규)**: S2 + **F8(베이지안 log5)** + **F17(shrinkage)** + **F16(난이도-능력 분리)** + **F6(엔티티 임베딩)** + **C5(최근윈도우 재캘리+prior-shift)**
4. **S4 (새 신호)**: S3 + **F9(시퀀스 임베딩, M12)** + **F7(xCTRL)+F23(miss-direction)** + **F21(series 메타피처)** + **M24/M25(random-effect 계열, M15와 같은 브랜치 비교)**
5. **S5 (딥 멤버·앙상블)**: M5/M6 (내부에 F6·F9·M10) + **T-e(멀티태스크)·T-f(soft증류)** → E1/E2 스택 + **E3(결합함수)·E4(top-k 재활용)** → **C3·C4**
6. **S6 (탐색)**: M18(TabPFN 콜드스타트), M17(GNN), **M26(상태공간)+F20**, **M29(EBM 해석성)**, T-b/T-c 타깃 프레이밍, F11/F12 자동피처, **P4(pseudo-label)·P6(안정성 지표)·P8(제출 페어링)** — 개별 A/B
7. **S7 (탐색 예산 ~20%, 반드시 실행)**: M7·M9·M11·M13·M19 + **M20·M21(LLM예측기)·RL피처선택** + **M27·M28·M30~M34(다양성원 롱샷)** + **M35·M36(저-prior)** + F22 — 낮은 사전확률이지만 **동일 CV 게이트로 공정하게** 실행. 서프라이즈가 여기서 나온다. baseline을 이기면 즉시 승격.
   - 저-prior라고 대충 돌리지 말 것 = 공정성(임베딩·튜닝 예산) 지켜야 결과가 유효.

```
[공통 장착]    C6(클립+3지표) P2(recency) P3(refit) F29(ABS-era) F30(시즌 상대화)

[주력]        M4                     + F3 F4 F5 F15 F18 F19 F24 F31 + C2 C5 E1
[신규 브랜치]  M5 M6 M10 M12 M15 M18 M24 M25 M29 + F6 F7 F8 F9 F16 F17 F21 F23 F25 F26 F27 F28 F32 F33 + E2 E3 E4 C3 C4 T-e T-f

[저-prior 탐색] M20 M21 M35 M36 F36 (LLM예측기, RL피처선택, 확률적부스팅, 신규딥, 외부조인) ← 버리지 말고 공정하게 실험
```

> ⚠️ 무엇을 하든 **누수 0 · 시간분할 · 리샘플링 금지 · 매 단계 baseline 대비 캘리 검증**은 공통 고정(=`05` 6장). 이 게이트가 서프라이즈를 안전하게 채택하는 장치.
> **하드 제외 없음**: 모든 후보를 동일 게이트로 실험하되, 예산만 prior로 배분(고-prior 다수 시도 / 저-prior 소수라도 공정하게).
> 라벨 정의/지표가 확정되면 P1부터 자동 스윕 태스크를 짤 수 있음. 스윕은 **explore-exploit(예: successive halving/bandit)**로 저-prior 후보에도 최소 예산을 보장.
