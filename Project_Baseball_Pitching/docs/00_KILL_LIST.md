## 3. 사용자 결정 — 증류 트랙 종료 (2026-08-05)

`07_llm_to_train_model.md` · `08_distillation_plan.md`의 teacher→student 트랙은
**D4(자기증류) 하나만 남기고 종료**한다. D4의 존치 사유도 정확도가 아니라 **배포 안전**이다 —
앙상블을 의존성 0 아티팩트로 증류해두면 `lightgbm` 등 미검증 패키지를 `requirements.txt`에서 뺄 수 있다.
A100 학습 계획도 함께 종료. (근거: 핵심 arm이 규정상 사망 + 조건부 신호가 AUC≈0.53으로 미약)

## 5. 규정 확정으로 **새로 열린** 후보 (부활·신설)

라벨이 위치 기준 도넛이고 `asof_pitcher_middle_rate`·`asof_pitcher_reverse_rate`가 공식 컬럼이라는 사실에서 파생.

| ID | 내용 | 상태 |
|---|---|---|
| **N2** | `outside_rate = clip(1−succ−rev−mid, 0, 1)` — 세 번째 실패유형이 사실상 제공됨. **검증: 잔차 ≥0 비율 >99%, 중앙값 0.106** | Phase F arm B |
| **N3** | 카운트 × 실패유형 상호작용(`three_ball×middle_rate`, `two_strike×outside_rate`) | Phase F arm B |
| **N4** | 공격성(`ball_rate−strike_rate`)의 역U 반응 — 링 모양 성공영역의 직접 귀결 | 대기 |
| **N7** | 콜드스타트 fallback 룩업 (2025에 train 최대 초과 ID 실재) | 대기 |
| **N9** | `pitcher_team_id×season` 평균 reverse rate = 배터리/포수 프록시 (F34의 유일한 생존 잔재) | 대기 |
| **N10** | 고의 유인구 셋업 플래그 — "크게 벗어남"이 실패로 라벨되므로 의도적 볼이 라벨을 오염 | 대기 |
| **N1** | 실행오차 역산(landing = aim + 2D Gaussian, 3률에서 조준반경·분산 역산) | 논문용, 점수 트랙에서 제외 |
