## 7. 트랙맨 재설계 실측 (08-30, 유저 "둘 다 순차로") — 게이트 통과 매칭 못 만듦

각도3 설계 ⓒ+ⓑ를 실측. 배포 무관(N13은 real_data 미스플라이스), 매칭 정밀도만 측정.

| 단계 | Tier1 (엔티티/행가중) | 판정 |
|---|---|---|
| 기존 (고정 25분위 τ=0.72) | 51.4% / 78.2% | GO (검증된 상태) |
| **ⓒ GMM Tier컷** (antimode τ=2.01) | 22.6% / 52.7% | GO — 순도↑ **커버리지↓** |
| **ⓒ+ⓑ joint** (월×투구수, 요일 안전) | 18.8% / **45.2%** | **NO-GO** — 역효과 |

- **ⓒ GMM**: margin_row 뚜렷한 이봉(μ=0.86/2.64) → 하위 67% 저마진 배제. 순도는 오르나
  커버리지를 78→53%로 깎아 N13 검정력(표본 의존)엔 유불리 불명. 각도3 유효 설계라 보존.
- **ⓑ joint(요일 안전 월×투구수)**: **NO-GO(45.2%)**. 요일 없이는 각도3 핵심(선발 로테이션=
  요일×투구수)을 못 살리고 32차원 희소 Hellinger 노이즈만 추가 → 확실 매칭 감소. **되돌림.**
- **각도3 원안(요일 joint + 예약차원 재지정)**: 요일을 비용에 쓰려면 permutation 예약축을
  카운트상태분포/top_bottom으로 교체해야 하나 그 축들은 투수 정체성과 약상관이라 검증 약화
  리스크. 변동성 피처(`_measure_cells` 분위수 저장 확장) + N13 게이트(real_data 스플라이스)와
  함께 **다일 작업 = 다음 세션**(런북 §8).
- **결론**: 트랙맨은 이번 세션에 게이트 통과 매칭을 못 만듦. 각도3 예측(그림자블록·단독 폐쇄)
  재확인. 유일한 새 정보축이나 컷 1135 미달은 불변.

## 8. 라운드6 최종 — 실질 종결

**최신 논문 4각도 + 미탐색 카드(N32·N34) + 유일 생존(NOMADD) + 트랙맨 ⓒⓑ — 전부 실측/판정
종결. §5 안에서 컴플라이언트 1058.60을 넘는 경로 0건.** 컷 1135는 §5 위반 없이 도달 불가
(§7 세그먼트 오라클·d 벽·문헌 §5 3중 확인). 대회 점수는 라운드6으로 실질 종결. 남은 유일
미완(트랙맨 완전 재설계 → T1.5)도 컷 미달 확정, 순위 아닌 Phase3 발표 가치 목적.
