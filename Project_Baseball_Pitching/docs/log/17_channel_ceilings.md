# 17. Phase 0 — 채널 상한 오라클: 460점이 어디에 있는가 (그리고 어디에 없는가)

작성 2026-08-06. 코드 `sweep/oracle_ceiling.py`. 프로토콜 = val 2024(253,507행, r=0.4861).
기준선: june853 로컬 707.90 · **ENS-2 로컬 773.48 → 2025 실측 911.18** · 1위 1,371.40(로컬 환산 ≈1298).

## §0 결론 (세 줄)

1. **투수·타자·상황 식별 채널은 이미 소진됐다.** 각 채널의 **오라클 상한**(그 시즌 실제 성공률을
   안다고 가정)이 **우리 현재 점수보다 낮다**. 폐기 트랙의 "투수 스프레드 20% 과수축" 가설은 **사망**.
2. **용량 튜닝도 소진됐다(+2.1).** june이 물려준 `leaves 15 / min 1000`이 전이 체제에서 거의 최적이다.
3. **남은 412점은 "피처 부족"이 아니라 "시즌 전이 비용"이다.** 같은 시즌 데이터가 있으면 같은 피처로
   **1185.9**가 나오는데, 직전 시즌으로만 학습하면 773.5다. 그리고 목표 1298은 그 상한마저 넘는다
   ⇒ **새 정보(트랙맨)가 없으면 1371은 원리적으로 불가.**

## §1 식별 채널 오라클 — 전부 현재 점수 미만 (leave-one-out, val 라벨 사용)

| 오라클 | 캘리 후 점수 | std(p) |
|---|---|---|
| **O1 투수** (K=50) | **723.9** | 0.0457 |
| O1 투수 (K=0 / 200 / 500) | 707.3 / 720.4 / 706.0 | |
| **O1+O2 투수+타자**(로짓 가산) | **757.9** | 0.0449 |
| O1×O3 투수×카운트 | 510.8 | 0.0274 |
| O2 타자 (K=200) | 78.2 | 0.0189 |
| O3 상황(카운트·아웃·주자·초말) | 24.6 | 0.0162 |
| — **ENS-2 (실제 모델)** | **773.5** | |

**각 투수의 그 시즌 실제 성공률을 정확히 알아도 723.9**다. 우리 모델은 이미 773.5다.
투수·타자 오라클을 합쳐도 757.9로 여전히 미달. **asof 피처가 식별 정보를 이미 다 담고 있다**는 뜻이고,
"투수 해상도를 높이면 된다"는 방향은 **닫혔다**. (교차적합에서도 확인 — `C5 53피처+투수ID` 1142.7 <
`C1 53피처` 1185.9로 **투수 ID를 넣으면 오히려 떨어진다**. 타자 ID는 994.3으로 더 나쁘다.)

## §2 피처셋 상한 — 같은 시즌 데이터가 있을 때 (val 안 5-fold 교차적합)

| 용량 | 캘리 후 |
|---|---|
| leaves 7 / min 1500 | 935.2 |
| leaves 15 / min 1000 (june) | 1043.5 |
| **leaves 31 / min 500** | **1185.9** |
| leaves 63 / min 300 | 1170.8 |
| leaves 255 / min 100 | 53.7 (붕괴) |

**현 53피처에는 1185.9만큼의 신호가 있다.** 우리는 773.5를 뽑고 있으니 **412점이 남아 있다.**
다만 그 412는 피처가 아니라 **시즌 경계**에 막혀 있다 — 아래.

## §3 결정적 대비 — 용량 최적이 체제에 따라 정반대다

같은 격자를 **실제 프로토콜(fit 2023 → val 2024)**에서 다시 돌렸다:

| 용량 | 같은 시즌(5-fold) | **전이(fit 2023 → val 2024)** |
|---|---|---|
| leaves 7 / min 1500 | 935.2 | **699.5** ← 최적 |
| leaves 15 / min 1000 (june) | 1043.5 | 697.4 |
| leaves 31 / min 500 | **1185.9** ← 최적 | 690 미만 |
| leaves 127 | — | 558~587 |

**같은 시즌이면 용량을 키울수록 좋고, 전이면 키울수록 나쁘다.** 추가 용량이 잡아내는 것은
**그 시즌에만 있는 구조**라서 시즌 경계를 못 넘는다. june 파라미터는 전이 체제에서 이미 최적이고,
남은 여지는 **+2.1**뿐이다 ⇒ **Phase D(파라미터 탐색)는 종료.**

## §4 1371은 도달 가능한가

- 현 피처셋의 **같은 시즌 상한** = 1185.9 (2024 기준). 2025가 2024보다 138점 쉬운 시즌이라면
  같은 조건에서 ~1324.
- 목표 로컬 1298은 **2024 상한 1185.9를 이미 넘는다.**
- ⇒ **현 47공식컬럼 유래 피처만으로는 1371에 도달할 수 없다.** 1위는 다른 정보를 쓰고 있고,
  규정(§6)이 허용하는 다른 데이터는 **`trackman_history` 하나뿐**이다.

## §5 우선순위 개정

| 채널 | Phase 0 판정 | 조치 |
|---|---|---|
| 용량·파라미터 | +2.1 | **종료** |
| 투수/타자/상황 해상도 | 오라클이 현재 점수 미만 | **종료** (D-14 재심도 불필요) |
| **시즌 전이 비용** | 412점이 여기 막혀 있다 | **승격** — Phase 2(시즌 센터링)가 직격 |
| **트랙맨** | 목표가 현 피처 상한을 넘음 | **필수** — 유일하게 남은 새 정보원 |
| 수축 피처 확장 | 식별 채널 소진과 같은 계열 | 하향(싸니 시도는 함) |

**Phase 2(시즌별 타깃 센터링)가 1순위가 된다** — "412점이 시즌 경계에 막혀 있다"는 진단에 정확히
대응하는 유일한 값싼 수단이고, 성공하면 학습 데이터가 253k → 1.2M이 된다.
**Phase 3(트랙맨)은 선택이 아니라 필수**임이 §4로 증명됐다. 매칭은 이미 검증 통과 상태다.
