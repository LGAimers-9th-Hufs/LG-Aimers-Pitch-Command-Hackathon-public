## 1. 한 줄 결론

> **이 대회는 신호 발굴 대회가 아니라 캘리브레이션 대회다.**
> 베이스라인 총점이 549점인데, 예측 평균을 실제 성공률에 맞추는 것만으로 ±수백 점이 움직인다.

## 2. S0 진단 — base-rate 드리프트의 레버리지 (실측)

전제: `Score = max(0, 100000 × (1 − Brier/(r(1−r))))`. 상수 예측 p에 대해
`Brier = r(1−r) + (p−r)²` 이므로 **오프셋 손실 = (p−r)²/(r(1−r))**. r≈0.49에서 d=0.03 → **−360점**.

시즌 성공률은 단조 하락한다: 2019 .5647 → 2020 .5327 → 2021 .5328 → 2022 .5289 → 2023 .5000 → 2024 **.4861**.

### 실측 결과 (train ≤(val−1) → val, 주최 베이스라인 RF 설정 그대로)

**val = 2024** (train 평균 .5316 / 실제 r .4861)

| 예측 | Score |
|---|---|
| 상수 = train 전체 평균 (.5316) | −827.9 |
| 상수 = 직전 시즌 평균 (.5000) | −76.8 |
| 상수 = 3시즌 선형 외삽 (.4877) | **−1.1** |
| 상수 = 실제 r (상한) | 0.0 |
| RF 무보정 (예측평균 .5012) | 415.6 |
| RF + 직전시즌 평균 정합 | 430.0 |
| RF + **3시즌 외삽 정합** | **505.9** |
| RF + 실제 r 정합 (상한) | 507.0 |

**val = 2023** (train 평균 .5395 / 실제 r .5000)

| 예측 | Score |
|---|---|
| 상수 = 3시즌 외삽 (.5277) | −307.3 |
| RF 무보정 | −660.5 |
| RF + 실제 r 정합 (상한) | **−514.5** |

### 읽어야 할 것 3가지

1. **평균 정합이 +90점** (2024 폴드). 모델을 바꾸는 것보다 크다.
2. **2023 폴드에서 RF는 기후값(0점)보다 나빴다** — 실제 r로 완벽 보정해도 −514.
   즉 조건부 신호가 음(−)의 가치를 낼 수 있으며, **기울기 캘리브레이션(isotonic)이 필수**다.
   (서브샘플 리허설에서 isotonic 적용만으로 +777점 확인)
3. **외삽의 정확도가 곧 점수다.** 2024는 외삽 .4877 vs 실제 .4861로 거의 적중했지만,
   2023은 .5277 vs 실제 .5000으로 크게 빗나갔다(2023이 급락한 해). **외삽은 유용하나 불확실**.

## 3. 2025 base rate — 대회 최대 베팅 지점

2022~2024(.5289/.5000/.4861) 선형 외삽 → **2025 ≈ 0.462**.
2024 수준 유지(0.486) 가정과 0.024 차이 = **약 ±230점**.

- 리스크 대칭: 어느 쪽으로 틀려도 비슷한 크기로 잃는다 → **중간값(≈0.472~0.478) 헤지**가 기대손실 최소.
- 하락 요인: 2025 ABS 존 v2(1cm 하향)로 존 기하가 바뀜, 피치클락 정식 시행.
- 반등 요인: 하락이 이미 4년째라 평탄화 가능성. 2020→2021은 실제로 +0.0001로 정체했다.

### LB 프로빙으로 r을 역산하는 방법 (제출 예산 허용 시)

모든 예측에 로짓 오프셋 δ를 더하면 `Brier(δ) = B₀ + 2δ(m_p − r) + δ²` (근사, 확률공간 가산 시 정확).
서로 다른 δ의 제출 2~3회 점수를 연립하면 **미지수 r과 B₀를 풀 수 있다.**
공개 점수만 이용하므로 test 행 참조 금지 규정에 저촉되지 않는다. 초반 제출 슬롯 2~3회의 가치가
어떤 모델링보다 크다.

## 4. 규정이 무효화한 계획들 (요약)

별첨 §5·§6은 **test 행 간 참조를 전면 금지**한다. 결과:

- 자체 as-of 피처(F1 계열) **계산 불가** → 공식 `asof_*` 19컬럼이 유일한 이력 소스
- P4(test pseudo-label) **금지**
- P1(2025 입력 대상 adversarial validation) **불가** — 로컬 test는 5행뿐
- 허용 우회로: **train/trackman 기반 고정 룩업을 zip에 동봉**해 행 단위로 조회

## 5. 트랙맨 — 격상된 난제이자 유일한 미개척 신호원

- 1,793,078행 × 30컬럼, 2019~2024. **투구 위치 컬럼 없음**(구속·회전·무브먼트·릴리스만).
- **ID 체계 분리**: `pitcher_trackman_id`(906명) ∩ `pitcher_id`(792명) = **∅**.
  팀도 실명(구단 코드)이고 `MIN_*`(2군)이 섞여 있다.
- → 쓰려면 **엔티티 매칭**이 선결. 단서: 시즌 × 손 × 투구수 × **구종믹스**
  (메인의 `asof_pitcher_{fastball,breaking,offspeed}_rate`와 동일 정의로 계산 가능) × 팀 규모.
- 매칭 성공 시 얻는 것: 릴리스 일관성(미니 Kirby, F18), 구위 프로필, 구종별 무브먼트 분산 →
  **콜드스타트 투수 보강**. 신인은 이력이 얕아 `asof_*`가 약한데 트랙맨엔 있을 수 있다.
- 비용/불확실성이 크므로 **캘리브레이션 정비 이후** 착수한다.

## 6. 우선순위 (재편)

| 순위 | 항목 | 근거 |
|---|---|---|
| 1 | **isotonic(기울기) + 평균 정합(prior-shift) 2단 캘리브레이션 확립** | 실측 +777 / +90 |
| 2 | **2025 r 추정 전략** (외삽 vs 평탄 vs 헤지, 가능하면 LB 프로빙) | ±230점 |
| 3 | 시간분할 프로토콜 확정 (fit ≤2023 / calib 2024 / predict 2025) | 제출 구조와 동형 |
| 4 | 모델 탐색 (HGB·GBDT 라이브러리·recency 가중) | 신호 자체가 약함(AUC≈0.52~0.53) |
| 5 | 트랙맨 엔티티 매칭 → 콜드스타트 피처 | 유일한 미개척 신호원 |
| 6 | 실패유형(한복판/역방향) 구성비를 쓴 스타일 축 피처 | 공식 asof에 이미 존재, 저비용 |

## 7. 실행 방법 (시뮬레이션 준비 완료 상태)

```bash
cd Project_Baseball_Pitching
python sweep/run_real.py --sample 300000 --folds 2024 --models hgb   # 리허설 (~20초)
python sweep/run_real.py --folds 2023,2024                            # 본 실행 (전체 데이터)
python sweep/run_real.py --folds 2024 --no-record                     # 최종 게이트 폴드만
```

- `sweep/real_data.py` — 로더 + **규정 안전(행 단위) 피처 82개**(공식 47 + 파생 35) + 시간분할 폴드
- `sweep/run_real.py` — 베이스 모델 5종 × 캘리브레이션 변형 6종 교차 평가, 대회 산식 리더보드,
  `results/runs/`에 run.json 자동 기록
- 베이스 모델을 폴드당 1회만 학습하고 그 위에 캘리 변형을 얹어 교차곱을 싸게 얻는 구조
- `oracle_*` arm은 val 라벨을 쓴 **상한선 표시**이며 채택 대상이 아니다(리더보드에 격리 표기)
- 앵커 = 주최 베이스라인 RF 설정 그대로. 공식 LB 기준선 **549.51**과 나란히 표시된다
