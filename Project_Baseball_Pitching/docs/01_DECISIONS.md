## D-01. 게이트 지표를 LogLoss → 대회 공식 산식으로 교체 (2026-08-05)
- **왜**: 공식 지표가 `max(0, 100000×(1 − Brier/(r(1−r))))`로 확정.
- **영향**: 방향이 반대(클수록 좋음)라 정렬·비교·delta 부호가 전부 뒤집힌다. 합성 시절 run 5건은
  부호 규약이 반대라 `results/archive_synthetic/`으로 격리했다. 두 소스를 한 표에서 비교 금지.
- **되돌리기**: 없음(공식 지표).

## D-02. 증류 트랙(07/08) 종료, D4만 존치 — 사용자 확정
- **왜**: 핵심 arm이 규정상 사망(S3/S4 시퀀스 student는 test 행 간 참조 없이 입력을 못 만든다),
  F13은 엔티티가 익명 정수라 원리적으로 불가, T-e는 보조 라벨 부재.

  `requirements.txt`에서 뺄 수 있다.
- **되돌리기**: 규정 해석이 바뀌거나 주최가 데이터를 추가 제공하면 재검토.

## D-03. 캘리브레이션 상수는 참조 시즌에서 1회 산출해 **얼린다**
- **왜**: 예측 배치의 평균을 보고 이동시키는 방식(구 `match_mean`)은 §5의
  "평가 데이터 전체를 보고 만든 사후 보정값"에 해당한다. **라벨을 쓰지 않아도 위반**이다.
- **근거**: `data_description.md` §5. `test_regulation.py::test_no_batch_statistics`가 재발을 막는다.
- **비용**: cal 시즌에서 맞춘 평균이 val 시즌에서 그대로 유지되지 않는다(전이 손실) →
  드리프트 보정 상수 Δ̂로 상쇄한다(K2).

## D-04. 주 게이트 = V24(2024 검증), 나머지 폴드는 guard
- **왜**: V24만 제출과 동형(fit1 ≤2022 / cal 2023 / fit2 ≤2023 / val 2024 ↔ 제출은 한 시즌씩 뒤).
  그리고 폴드 평균은 V22(+2077)가 지배해 순위를 왜곡한다.
- **채택 규칙**: `V24 ≥ 현재 최고 + 2×paired SE` **그리고** `최악 폴드 ≥ 현재 guard − 여유`.
  고정 임계 ±15는 폐기 — 같은 모델의 상수 비교는 SE≈8점이지만 다른 base model 비교는 30~50점이다.

## D-05. 제출 후보 = `hgb82 + isotonic + game_type 세그먼트 앵커(w=0)`
- **왜**: V24에서 최고점(`hgb82+K3_flat` 656.5)보다 137점 낮지만(519.0), 최악 폴드가
  **−1440.8 → +356.7**로 바뀐다. 2025는 ABS 존 v2라는 알려진 체제 변화가 있고,
  test의 `game_type` 구성비를 볼 수 없다.
- **w=0의 의미**: F 세그먼트에 R의 목표 성공률을 그대로 준다. F는 2022→2023에 −0.236 붕괴한
  이력이 있어 F 자체 추세를 외삽하는 것이 더 위험하다.
- **되돌리기**: 제출 결과로 2025의 체제가 안정적이라는 증거가 나오면 K3_flat 계열로 전환.

## D-06. 리더보드는 **사전 등록 후보 중 선택**에만 쓴다
- **왜**: 점수 차로 r을 역산해 그 값을 상수로 박으면, §5의 "전체를 보고 만든 사후 보정값"이라는
  해석이 가능하고 상위 100명 코드 검증에서 방어가 어렵다.
- **어떻게**: 제출하는 모든 zip의 앵커 상수는 **train에서 유도**되고 그 유도식이
  `calib.json.provenance`에 문자열로 남는다. 공개 점수는 "내 후보 중 어느 것이 좋았나"를
  고르는 데만 쓴다 — 리더보드 형식에 내재된 정상 관행이다.
- **대가**: 후보 격자 해상도만큼의 손실(≈10~25점).

## D-07. 로컬 환경을 서버에 맞추지 않고, 대신 폴백을 넣는다
- **배경**: 로컬 numpy 2.2.6 / Python 3.13 vs 문서상 서버 numpy 1.26.4 / Python 3.11.15.
- **실측**: 주최가 배포한 `rf.pkl`이 `numpy._core.multiarray`를 참조한다 = **numpy 2.x로 직렬화**.
  그 pkl이 서버에서 549.51을 냈으므로 **서버 런타임은 numpy 2.x**이고, 문서의 "사전 설치 1.26.4"는
  `pip install -r requirements.txt` 이후 실제 런타임과 다르다. sklearn은 1.8.0으로 정확히 일치.
- **결정**: 핀 고정 venv를 만들지 않는다. 대신 `script.py`에 **언피클 실패 시 순수 numpy 폴백**을 둔다.
  Python 마이너 버전 차이는 리허설이 불가능한데, 실행 오류는 제출 횟수를 차감하기 때문이다.
- **검증**: `verify_submission.py`가 모델 파일을 손상시킨 경로까지 실행해 확인한다.

## D-10. 첫 제출 부검 → 게이트·스택 전면 교체 (2026-08-05, 제출 S1 = 269.05)
- **사실**: S1(hgb82+isotonic+세그먼트앵커 0.4849) = **269.05** / 주최 baseline = 549.51 / LB 1위 = 931.
- **역산**: 두 점수 연립 + 적응 탄성 측정 → **r_2025 ≈ 0.513 ± 0.008. 6년 하락이 반등했다**
  (ABS 존 v2 추정). 우리 하향 앵커 −168점 + isotonic의 refinement 파괴 −186점 = 스택이 −354점.
  무보정(hgb82+K0)이었다면 ~641점.
- **교체 1 — 게이트**: 로컬 순위를 score가 아닌 **refinement = score + 1e5·d²/(r(1−r))** 로.
  269 사태의 근본 원인은 앵커 운에 오염된 게이트였다(K4가 앵커 운으로 1위 → 실전에서 앵커가 반대로).
- **교체 2 — 레벨 분리**: 절편은 자유 스칼라 β 하나로 통제(임상 모델 업데이트의 "절편만 갱신" 원칙).
  Brier에서 평균 오차 δ의 비용 = 400,000·δ² — 레벨은 트리 속이 아니라 숫자 1개에 둔다.
- **교체 3 — isotonic 폐기**(제출 스택): −150~−190 refinement 세금 + 예측을 전년 수준에 고정해
  주최 `asof_prev*`의 2025 내 갱신(합법 온도계, 시즌 추적 기울기 0.83)과 싸운다.
- **근거 문서**: `docs/log/13_autopsy_and_v2.md` (부검 + 타 도메인 조사).

## D-16. N15(donut sign-flip) 기각 → 율 유래 피처 계열(Family A) 전면 종료 (2026-08-06, run 20260806-095501)
- **사전 관측검정은 통과했었다**(사전등록): 3볼 페널티 Δ ~ σ프록시 가중 OLS 기울기 +0.290,

## D-25. Phase 3(트랙맨 시즌 프로필) 기각 — 그리고 **로컬 게이트 오차막대 5배 교정** (2026-08-07)

3폴드(val 2024/2023/2022) × paired SE × 커버 층 분해 × **위약 대조**.

**① 계획의 가설은 반증됐다.** 드리프트는 병목이 아니었다 — 시즌단위+분위수(3폴드 평균 **−14.7**)가
커리어 원값(D-17 원형, **−7.5**)보다 나빴다. 어떤 형태도 base 대비 양수가 아니다.

**② 진짜 발견 — 우리 오차막대가 5~6배 과소평가돼 있었다.**

| 대조 | Δ 2024 | Δ 2023 | Δ 2022 | 평균 | **폴드 SD** | 폴드 내 paired SE |
|---|---:|---:|---:|---:|---:|---:|
| `noise6`(**균등난수 6컬럼**) | −6.8 | −15.0 | **+11.2 ±5.0** | −3.5 | 13.4 | ±5.0 |
| `t1_career_rank`(최고 실arm) | +4.4 | −44.6 | +26.6 | −4.6 | 36.4 | ±6.5 |

**순수 난수 6컬럼이 val 2022에서 2SE를 통과한다(+11.2 ±5.0).** D-17의 "+11.4 ±9.3, 2SE 18.6"과
같은 크기다 — 그때의 "효과는 있으나 저검정력" 판독은 틀렸고, **효과가 섭동 잡음 폭 안이었다.**
커버 층 분해가 먼저 이걸 드러냈다: 피처가 NaN일 수밖에 없는 **비커버 행에서 Δ가 더 크게 움직였다**
(val 2023 −135.4 vs 커버 −26.2). 컬럼 추가 → `feature_fraction` 추첨·분할 경쟁 변화 → 트리 전체 재배치.

⇒ **채택 규칙 개정(소급 적용)**: 피처 arm은 `3폴드 평균 > 0` **및** `평균 > 폴드 간 SD`를 동시에 만족해야
한다. 폴드 내 paired SE는 오차막대가 아니다. 과거의 "로컬 +11이면 유망"류 판독은 무효.

**③ 매칭 자체는 살아남았다.** 시즌 내에서 값을 투수 사이에 재배치한 **셔플 위약**과 비교하면
`career_rank` 진짜 − 셔플 = **+27.5 / +74.3 / +3.8 (3/3 양수, 평균 +35.2)**. Hungarian 매칭은 실제
정보를 담고 있다(P1의 permutation z=26.2와 독립 재확인). 문제는 정보가 아니라 **운반 방식**이다 —
53피처 강정칙 트리에 자유 컬럼 6개를 얹는 비용이 정보값보다 크다.

⇒ 트랙맨은 죽은 채널이 아니라 **형태 미정 채널**로 남긴다: T-a 스칼라 1컬럼 압축 / T-b 커버 층 전용
별도 앙상블 멤버(트리 구조를 안 건드리고 june 채택 기준으로 직접 심사) / T-c 커버리지 확대(운반 방식
확정 후에만). `cov_only ≈ 0`이므로 "매칭된 투수 = 1군 주력" 교락은 배제됐다.

서빙 경로 변경 없음. 챔피언 ENS-2(로컬 773.48 / 2025 911.18) 불변.

**철회하는 결론 2건**: ①"남은 412점 = 시즌 전이 비용" ②"1371은 현 피처로 원리적 불가 ⇒ 트랙맨이

**대신 남는 그림: 우리는 이미 이 피처셋의 정직한 상한에 있다.** 그리고 이것이 지난 몇 달의 모든 0을
