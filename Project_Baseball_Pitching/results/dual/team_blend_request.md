# 팀 블렌드 타당성 측정 — 팀원 요청서 (전달용)

안녕하세요! 현재 저희 쪽 제출물(ENS-7, LB 1003.51)과 팀원 모델을 **확률 평균 블렌드**로 합치면 점수가 오를 수 있는지 정량 측정하려 합니다. 근거는 Brier 항등식입니다:

> `Brier(평균) = 평균Brier − mean((p_A−p_B)²)/4` — 두 모델 예측의 불일치 RMS만 알면 블렌드 이득이 **수학적으로 보장**됩니다. 서로 다른 정보를 쓰는 모델일수록 불일치가 커서 이득이 큽니다 (예: 두 모델이 동급일 때 RMS 0.025 → 약 +20점, 0.030 → +45점).

## 요청 사항 (가능한 것만이라도!)

### ① 검증 폴드 예측 CSV (가장 중요)
본인 **제출 파이프라인과 동일한 방식**(전처리·모델·캘리브레이션 그대로)으로, **학습 데이터만 컷오프**해서 아래 시즌을 예측한 CSV를 보내주세요:

| 파일명 | 학습 데이터 | 예측 대상 |
|---|---|---|
| `team_pred_2024.csv` | train의 season ≤ 2023 | season == 2024 전체 행 (253,507행) |
| `team_pred_2023.csv` (가능하면) | ≤ 2022 | season == 2023 (245,525행) |
| `team_pred_2022.csv` (가능하면) | ≤ 2021 | season == 2022 (247,472행) |
| `team_pred_2021.csv` (가능하면) | ≤ 2020 | season == 2021 (247,088행) |

- 포맷: `row_id,pred` 두 컬럼, UTF-8, 헤더 포함. row_id는 train.csv의 값 그대로, **train.csv 원래 행 순서 유지**.
- pred = **최종 제출 형태의 확률**(후처리/캘리브레이션 적용 후 값).
- 최소 2024 하나만 있어도 측정 시작 가능합니다.

### ② 현재 LB 실측 점수
제출해본 적 있다면: 제출 파일명 + 리더보드 점수. (없다면 "미제출"이라고 알려주세요 — 블렌드 가중 확정에는 실측 점수가 필요해서, 필요시 슬롯 1개로 단독 점수를 재는 것도 검토합니다.)

### ③ 사용 정보 요약 (5~10줄)
어떤 피처/정보를 쓰는지 간단히: 공식 컬럼 중 어떤 것, 파생 방법, 트랙맨 사용 여부, 학습 시즌 범위, 모델 종류. → 규정 §5(평가 데이터 행 간 참조 금지) 준수 확인과 "서로 다른 정보인가" 판단에 씁니다.

### ④ (가능하면) 단독 제출 zip
본인 모델 단독의 submit.zip 형태 파일. → 결합 제출물을 만들 때 저희 검증 하네스(서버 환경 재현·파리티 검사)에 그대로 태울 수 있습니다. 없으면 저희가 패키징을 도와드립니다.

## 저희가 돌려드릴 것
- 불일치 RMS 실측 + 블렌드 기대 이득 + 최적 가중 계산 결과
- 채택 기준(로컬 +10 이상, 3개 폴드 검증) 통과 시: 결합 제출물 빌드·검증까지 저희가 수행

## 참고
- 저희 쪽 폴드 예측은 이미 캐시되어 있어(4개 폴드 전부), CSV 도착 즉시 측정 가능합니다.
- 예측 CSV는 train.csv에서 만들 수 있는 값이라 규정 문제가 없습니다 (평가 데이터와 무관).
