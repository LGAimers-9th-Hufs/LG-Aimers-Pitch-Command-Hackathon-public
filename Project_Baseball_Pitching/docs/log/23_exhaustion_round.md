(직전 완결 시즌 rate, 추세, 장기 변동성, 타자 당해분)를 전부 소진 시험.

| E1 직전 완결 시즌 rate | −0.8 | −9.0 | +5.7 | **−1.4** | **위약(−2.2)과 구별 불가** |

### ⚡ is4 원리의 정정 (이 라운드의 진짜 산출물)

E1도 "트리가 만들 수 없는 per-투수 상수"인데 0이다 ⇒ 가설이 틀렸다.

**맞는 설명**: per-(투수,시즌) 상수 채널은 **오라클이 예고한 그대로 포화**다(투수 723.9 < 현재 877.8).
트랙맨 프로필(투수-시즌 상수)이 죽은 것도 같은 법칙. **is4가 통한 이유는 `is_n`이 시즌 내내
행마다 자라는 — (투수,시즌) 안에서 변하는 — 값이었기 때문**이다.

**⇒ 새 피처 판별 기준 한 문장: "이 값이 한 투수의 한 시즌 안에서 변하는가?"**
아니오 → 포화 채널, 구현하지 않는다. (Program G(트랙맨 스칼라)가 이 기준으로 사전 기각됐다.)

## 2. Program F — 선택 절차: 고쳤으나 풀이 비었다 (`ens5_select.py`)

- 초판 "2폴드 점수 평균" 그리디는 **스케일 지배로 폭주** — 파단 연도(V23)의 점수 가동폭(±600)이
  안정 연도(±10)를 삼켜 `lin_f60_0`에 w=0.95를 몰아주고 미사용 폴드 −565.
  **교훈: 다폴드 그리디는 점수 평균이 아니라 기준 구성 대비 개선분의 maximin으로.**
- maximin 교정판: **+1.22(V24) / +5.47(V23) / +1.66(V22, 선택 미사용)** — 셋 다 양수로 절차는 건전.
  그러나 크기가 로컬 +1.2 = 제출 기준(+10) 미달. **19종 풀에는 ENS-4에 더할 것이 없다.**

## 3. Program H1 — kNN 잔차 뱅크: 신호는 실재하나 분산이 이긴다 (`knn_residual.py`)

leave-own-pitcher-out + 잔차 셔플 위약 + 3폴드 × (k,w) 격자 6종:

- **실제 보정 Δ는 전 구성에서 평균 음수**(최선 −4.2).
- 순수효과(실제 − 위약)는 V23/V24에서 +2~+21로 **국소 구조가 미약하게 실재** — 그러나 kNN 평균이
  주입하는 분산이 그보다 크다. w 축소 시 신호 선형·분산 제곱 감소로 손익분기 ≈ **+1~2**. 채택 불가.
