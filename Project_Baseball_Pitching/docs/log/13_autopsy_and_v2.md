## 1. 부검 — 269점의 완전한 분해

### 1.1 r_2025는 하락이 아니라 **반등**했다

두 LB 점수(269.05 / 549.51)를 적응 탄성 측정과 연립하면 **r_2025 ≈ 0.513 ± 0.008**.
2024가 .4861이었으니 6년 연속 하락(.5647→.4861)이 반전됐다. r ≤ 0.50은 실현 가능 구간의
가장자리다(그 경우 우리 모델이 주최 RF보다 refinement가 ~155점 나빠야 하는데, 2024 실측은
+10 우위 — 모순). 유력 원인: 2025 ABS 존 v2(1cm 하향)로 존이 좁아져 "크게 벗어남" 판정 경계가
투수에게 유리하게 이동.

### 1.2 손실 명세 (r=0.510 기준)

| 항목 | 손실 | 메커니즘 |
|---|---|---|
| 하향 앵커(0.4849 목표) | **−168** | 실제는 0.51인데 아래로 당김 |
| isotonic | **−186** | refinement 파괴 + 예측을 2024 수준에 **고정** → 적응 채널 무력화 |
| 합계 | **−354** | 269 vs 무보정 641의 격차 거의 전부 |

즉 **모델은 죄가 없었다.** `hgb82+K0`(무보정)이었으면 ~641점 = 수료선 +90.

### 1.3 게이트가 오염돼 있었다

로컬 1위였던 `hgb82+K1K4_w0`은 **앵커 운**(V24에서 목표 .4969가 우연히 실제 .4861 근처)으로
1위였다. 앵커를 제거한 순수 성능(refinement)으로 다시 줄 세우면:

| arm | V24 score | V24 **refinement** |
|---|---|---|
| hgb82+K0 | 655.4 | **703.5** |
| hgb82+K1K4_w0 (제출본) | 519.0 | 523.2 |
| rf_official+K0 | 415.6 | 506.8 |

→ **게이트를 refinement로 교체**(D-10). 레벨(절편)은 별도 축으로 분리해 β 스칼라 하나로 통제.

### 1.4 상한 분석 — 남은 격차는 튜닝이 아니다

- 정칙화 강화(max_iter 300→150): refinement **+39** (703→742). 반대 방향(깊게·피처 추가·ID 제거)은
  전부 손해(−169/−208/−725).
- 현 모델 랭킹에 oracle isotonic을 씌운 상한 ≈ **740** — 튜닝으로 이미 도달.
- LB 1위 931(스킬 0.93%)까지 남은 **~190점은 새 정보 채널에서만 나온다**. 측정된 유일한 대형
  채널: **투수 해상도** — 이력 십분위 실측 스프레드 0.1095 vs 모델 0.0881(20% 과수축),
  oracle 투수 평균만으로 662점.

### 1.5 합법 온도계의 발견

주최 `asof_prev1/3/5` 컬럼은 **2025 평가 서버 안에서 계속 갱신**된다(검증 완료). prev5는 시즌
수준을 기울기 0.83·corr 0.99로 추적하는 **행 단위 합법 레짐 측정치**다. 그런데 모델은 이를
0.38만 소비(트리 정칙화의 감쇠) → 레짐 이동의 ~46%만 자가 보정. **이 채널을 제 기울기로
복원하는 것이 합법적 label-shift 보정이다** (Saerens/BBSE류는 test에서 prior를 추정하므로 불법).

## 2. 타 도메인 조사 — 병목 3개가 전부 타 분야의 표준 문제였다

(전 인용 arXiv/DOI 실재 검증. 상세 표는 플랜 파일과 run 기록에.)

| 우리 병목 | 그 분야 | 표준 해법 | 우리 구현 |
|---|---|---|---|
| 투수 효과 20% 과수축 | 보험 credibility · 야구 Marcel | **Bühlmann–Straub** Z=n/(n+K), K 모멘트 추정 → 분산이 구성상 맞는 수축 | `real_data.build_credibility` → 투수 로짓 룩업(train 유래, zip 동봉) |
| field 단위 잔여 편향 | CTR (Google/Meta) | 랭커 + **별도 캘리 레이어**(field-aware: WWW'20 10.1145/3366423.3380154, MCGrad KDD'26 2509.19884) | `recal.py`: `a + b·logit p + c·(z−z̄) + d·(t−t̄)` — **Brier 직접 최소화**(EMOS 원칙), 상수 4개 |
| 온도계 감쇠 | 보험 GBM-with-offset (NAAJ'21 1904.10890, CANN) | GLM이 레벨+온도계 소유, 트리는 잔차만 | `_OffsetBoost`: LR(prev5·커리어·타자·카운트) + HGBRegressor(squared_error) 잔차 — **지표가 곧 목적함수** |
| 상향 시프트 대응 | 임상 모델 업데이트 (Stat Med 2017) | 기울기는 안정, **절편만 드리프트** → 절편만 갱신 | 레벨 = 동봉 스칼라 β 하나. 사전 등록 격자에서 LB로 선택 |
| 앙상블 판단 | 앙상블 이론 (JMLR'23 2301.03962) | Brier 이득 = 4e5·s²(1−1/M) — **사전 계산 가능** | `_SeedAvg`가 실현 이득 직접 측정. 확률 평균(볼록성 → 비악화 보장), 로짓 평균 금지 |
| 최종 맵 | 2026 벤치(2601.19944) | isotonic/Platt이 강한 모델을 **훼손**, beta calibration 안전 | isotonic 폐기 실측(−186)과 독립적으로 일치 |
| 헤징 | 결정이론 | Brier는 proper → prior 불확실성 하 최적 = **사후평균**. 헤지 없음 | minimax 계열 전부 SKIP |

핵심 산수: `Score = 1e5·(1 − BS/0.25)` → **ΔBS 1단위 = 400,000점**. 평균 오차 δ의 비용 = 4e5·δ².
δ=0.027(올해 반전 폭) = 292점 — 절편 하나가 왕국의 열쇠다.

### 4.2 판정

- **채택: `glm_offset_hgb` (오프셋 부스팅) + K0 + β.** 주 게이트 +49(703→752), 역방향 폴드 1위,
  파단 연도 guard도 최선(−761 vs −1200대), 콜드스타트 1151. 조사 B2의 보험 GBM-with-offset
  패턴이 그대로 이겼다 — **온도계 복원은 외부 레이어가 아니라 모델 내부에서 GLM이 소유하는 형태가 옳았다.**
- **기각: GLM 재캘리 레이어(RC/RC2)** — 조사 1순위 후보였으나 게이트 탈락. 원인 두 가지:
  ① cal→val 전이에서 계수가 수축(b≈0.2~0.7; fit1 모델의 cal 예측에 맞춘 계수가 fit2 모델의
  val 분포와 어긋남 — isotonic과 같은 병의 순한 형태) ② 콜드스타트 파괴(z·t가 결측인 신인 행에서
  b<1 수축만 남아 −1100~−1700). 풀링(RC2)이 완화는 하지만(V24 675~718) K0를 넘지 못한다.
  → **v2 제출 스택에서 제외.** 아이디어는 킬이 아니라 보류: 전이 문제를 푸는 형태(예: fit2 모델의
  OOF로 적합)가 나오면 재시도.
- **기각: 시드 평균** — +0.1점(742.5→742.6). 교차 시드 분산이 무시 가능. 공식(4e5·s²)이 예측한 대로.
- cal=2023(파단 연도) 단일 적합에서 b가 0으로 퇴화하는 현상을 확인 — 계수 경계와 풀링을 넣었지만
  근본 원인은 위 ①이라 결론 불변.
