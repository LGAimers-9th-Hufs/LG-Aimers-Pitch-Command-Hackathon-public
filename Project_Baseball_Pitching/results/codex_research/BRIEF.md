```
대칭쌍 역산:  C = −(S₊+S₋−2S₀)/(2δ²),  δ* = (S₊−S₋)/(4Cδ),  G* = C·δ*²
전역 상수축 실측 C = 402,463 = 1e5/V  ⇒  V = 0.2484700,  r_2025 = 0.4609 또는 0.5391
mean_2025(raw) = 0.4680607 (LB 역산)
```

## 3. 조사 과제 — 각각 **기대 점수 · 필요 슬롯 · 실패 조건**을 숫자로 답해라

### 과제 1 ★ 분할축(partition) 다차원 프로빙의 비용 하한

지시자 축은 헤시안이 셀 비중으로 결정된다: 중심화 지시자 `g_i = 1_i − w_i` 에 대해
`E[g_i g_i] = w_i(1−w_i)`, `E[g_i g_j] = −w_i w_j` (평가셋 비중 = 동봉 상수일 때).
train 추정 비중을 헤시안으로 **가정**하면 k셀 축을 **k제출 이하**로 닫을 수 있는가?

- 비중 추정 오차가 최종 이득에 어떻게 전파되는가(1차? 2차?). 실패 임계는?
- `game_type:F` 실측(2025 비중 11.367% vs train 10.91%)으로 이 가정을 사후 검증해라.
- 후보 축과 로컬 V2024 오라클: `count12`=12.9 · `count4`=6.3 · `month`(폴드마다 부호반전) ·
  `inning` · `hand4`. **주의: 이 오라클들은 "로컬로 추정해 박는" 경로에서 기각된 것이고,
  LB로 적합하는 경로에서는 오라클이 곧 회수 가능액이다** — 이 구분이 이 과제의 핵심이다.
- 세그먼트 축들 사이, 그리고 세그먼트 축과 slope 축 사이의 교차항 크기
  (실측: `corr(g̃_F, final−0.5) = −0.184`, 교차비용 −2287점/단위²).

### 과제 2 캘리 형상 축 (아핀 너머)

D-35가 "아핀을 넘는 캘리 자유도는 전부 레짐 과적합"으로 닫았으나 **그건 로컬 게이트의 판정**이고,
그 게이트가 slope에서 0.107을 놓친 것이 어제 실증됐다 ⇒ 재심 대상이다.

```
곡률 축  g = (raw − raw̄)² − mean(·)     실측 mean(g²)=9.240e-06 → C_q = 3.72
3차 축   g = (raw − raw̄)³                                        → C_q3 = 0.0540
```
- 곡률/3차/로짓 재매핑 중 **어느 축의 기대 이득이 큰가**, 그리고 서로 직교하는가?
- 곡률이 작다 = 계수 여지가 크다. slope는 잔차와의 상관 0.87%로 +8.18을 냈다.
  같은 논리로 각 축이 +20을 내려면 필요한 상관은 얼마인가?
- 프로브 δ를 어떻게 고르는 것이 최적인가(무신호 비용 vs 역산 정밀도).

### 과제 3 ★ 블렌드 축의 LB 프로빙 대수

파트너 예측 `q_B`가 생겼을 때:
- 가중 `w` 와 **블렌드 후 아핀 재캘리(level·slope)** 를 최소 몇 슬롯에 닫는가?
  (순차로? 동시에? 어느 순서가 슬롯을 아끼는가?)
- **파트너의 레벨 오차가 블렌드 후 LB 재캘리로 흡수된다는 것을 식으로 증명하거나 반증해라.**
  (지금까지 팀 블렌드의 최대 리스크는 "팀원이 전 시즌 학습이면 `mean(p_B)−r≈0.06`,
  w=0.5에서 −362점인데 로컬 게이트가 못 본다"였다. 재캘리가 이걸 흡수한다면 심사 기준이
  **형상 불일치 s 하나**로 줄어든다 — 이게 맞는지가 이번 주 전략을 좌우한다.)
- 파트너 점수 `S_B`와 불일치 `s`의 함수로 **최적 w와 기대 이득 표**를 다시 만들어라
  (재캘리 이후 기준으로. 재캘리 전 표와 어떻게 다른가?).
- 파트너가 여러 개일 때(우리 + Codex 파트너 + 나중의 팀원) 슬롯 대비 최적 결합 순서.
